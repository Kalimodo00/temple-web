# 隨身一炷香

手機就是你的香。在廟裡、家中神明廳或拜祖先時，都能用手機上香、擲筊、求籤。

純靜態網站，不需要伺服器和帳號，資料只存在使用者的手機裡。可以直接放 GitHub Pages。

## 功能

| 項目 | 手機動作 | 沒有感測器時 |
|---|---|---|
| 上香 | 點香後雙手持手機鞠躬三次，再插入香爐 | 按「鞠躬一拜」三次 |
| 擲筊 | 手機小幅度往上抬一下 | 按「擲筊」 |
| 求籤 | 持續搖動手機，跳籤後擲筊確認，得聖筊才算數（拜祖先場景沒有求籤） | 連按「搖一下」 |
| 搧香 | 手指在畫面上滑動；手機左右傾斜，香煙跟著飄 | 滑鼠拖曳 |

其他功能：

- **香的設定**：細香、標準香、粗香；5 到 60 分鐘或自訂（1 到 240 分鐘）；1 炷或 3 炷
- **燃燒**：香依真實時間變短，關掉網頁再回來長度仍然正確
- **順序與禮儀**：依場景提供參考步驟
- **祖先與忌日**：支援農曆與國曆，七天內會在首頁提示
- **紀錄**：籤詩收藏、參拜紀錄
- **預設靜音**：只用震動，可在設定中開啟音效

## 架構

- `js/main.js`：畫面與儀式流程
- `js/incense.js`：香的規格與燃燒計算
- `js/smoke.js`：WebGL2 流體模擬的香煙，舊裝置退回 2D 粒子版
- `js/sensors.js`：鞠躬、甩動、搖晃偵測
- `js/lunar.js`、`js/lunar-table.js`：忌日計算與農曆月份表
- `js/store.js`：本機資料儲存
- `js/content.js`：場景文字與禮儀內容，**要改文字看這裡**
- `js/fortunes.js`：24 支原創示範籤詩

農曆使用內嵌的月份表，涵蓋到 2065 年。瀏覽器內建的中國曆在部分年份會差一天（例如 2027 年春節），所以不使用。

## 本機執行

```bash
npm start
```

開啟 http://localhost:5173 。測試用 `npm test`。

手機動作感應只在 HTTPS 下運作，所以手機測試請用部署後的網址。

## 部署到 GitHub Pages

1. 在 GitHub 建立 repository，把這個資料夾推上去
2. 到 Settings → Pages，Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`
3. 等一兩分鐘，網址會是 `https://<帳號>.github.io/<repo 名稱>/`

## 已知限制

- 資料只存在瀏覽器，換手機或清除瀏覽器資料後會消失
- 網頁關閉時無法通知香已燒完，要回到網頁才看得到
- 螢幕常亮只在網頁開著時有效，部分省電模式下會被系統拒絕
- 籤詩與禮儀內容是一般性的參考，不代表特定廟宇或家庭的做法
